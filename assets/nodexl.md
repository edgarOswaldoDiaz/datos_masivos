#### Análisis de Redes Sociales con NodeXL

**NodeXL** es una herramienta especializada en **Análisis de Redes Sociales (Social Network Analysis, SNA)** que se integra directamente como un complemento de **Microsoft Excel**, lo que la hace especialmente útil para perfiles que combinan análisis de datos, visualización y exploración interactiva de redes complejas sin requerir programación avanzada.

Tabla: ¿Qué es NodeXL y cómo utilizarlo?

| **Aspecto**                              | **Descripción detallada**                                                                                                                                                                                                                                                                     |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **¿Qué es NodeXL?**                      | NodeXL es una plataforma de análisis, visualización y exploración de redes sociales desarrollada por el *Social Media Research Foundation*. Funciona como un complemento de Microsoft Excel y permite analizar gráficamente relaciones entre entidades (nodos) y sus interacciones (aristas). |
| **Tipo de herramienta**                  | Herramienta de **Análisis Exploratorio de Redes (Exploratory Network Analysis)** con enfoque visual y estadístico. Está orientada a investigadores, analistas de datos, científicos sociales y profesionales de analítica digital.                                                            |
| **Entorno de ejecución**                 | Se ejecuta dentro de **Microsoft Excel**, aprovechando hojas de cálculo, tablas dinámicas y gráficos, lo cual reduce la curva de aprendizaje para usuarios familiarizados con Excel.                                                                                                          |
| **Modelo de datos**                      | Utiliza el modelo clásico de grafos: <br>• **Nodos (Vertices)**: representan individuos, cuentas, organizaciones, hashtags, etc. <br>• **Aristas (Edges)**: representan relaciones como menciones, retuits, respuestas, enlaces o interacciones.                                              |
| **Tipos de redes que soporta**           | • Redes dirigidas y no dirigidas <br>• Redes ponderadas <br>• Redes simples y multigrafo <br>• Redes temporales (interacciones en periodos específicos)                                                                                                                                       |
| **Fuentes de datos**                     | Puede importar datos desde: <br>• Archivos CSV / Excel <br>• APIs de redes sociales (X/Twitter, YouTube, etc.) <br>• Datos generados por encuestas, logs o sistemas transaccionales <br>• Exportaciones desde bases de datos o procesos Big Data                                              |
| **Obtención de datos de redes sociales** | NodeXL permite **conectar directamente con plataformas sociales** (principalmente X/Twitter) para recolectar datos como menciones, hashtags, respuestas y retuits, convirtiéndolos automáticamente en grafos.                                                                                 |
| **Métricas de análisis de redes (SNA)**  | Calcula métricas clave automáticamente, entre ellas: <br>• Grado (Degree) <br>• Centralidad de intermediación (Betweenness) <br>• Centralidad de cercanía (Closeness) <br>• Eigenvector Centrality <br>• Densidad de la red <br>• Componentes conexos                                         |
| **Detección de comunidades**             | Integra algoritmos de **detección de clústeres** como Girvan–Newman y Clauset–Newman–Moore, permitiendo identificar comunidades, grupos de influencia o sub-redes.                                                                                                                            |
| **Visualización de grafos**              | Proporciona múltiples layouts automáticos (Fruchterman-Reingold, Harel-Koren, círculo, espiral, etc.) y opciones avanzadas de formato visual: <br>• Tamaño de nodos por métricas <br>• Color por comunidad o clasificación <br>• Grosor de aristas por peso                                   |
| **Análisis exploratorio**                | Facilita la exploración visual interactiva de redes, identificación de actores clave, detección de patrones de interacción y análisis de estructuras de poder o difusión de información.                                                                                                      |
| **Integración con Excel**                | Permite usar filtros, fórmulas, tablas dinámicas y gráficos de Excel en conjunto con el análisis de redes, facilitando una analítica híbrida (estadística + visual).                                                                                                                          |
| **Casos de uso académicos**              | • Análisis de comunidades en redes sociales <br>• Identificación de influenciadores <br>• Estudio de difusión de información <br>• Análisis de colaboración científica <br>• Redes organizacionales                                                                                           |
| **Casos de uso en Big Data & Analytics** | • Análisis de conversaciones masivas <br>• Evaluación de campañas digitales <br>• Análisis de reputación y opinión pública <br>• Exploración de grafos como etapa previa a modelos avanzados                                                                                                  |
| **Ventajas principales**                 | • No requiere programación <br>• Excelente para enseñanza de SNA <br>• Visualización inmediata <br>• Integración con herramientas conocidas <br>• Ideal para análisis exploratorio                                                                                                            |
| **Limitaciones**                         | • Escalabilidad limitada frente a grafos extremadamente grandes <br>• Dependencia de Excel y Windows <br>• Menor flexibilidad que librerías como NetworkX, GraphX o Neo4j                                                                                                                     |
| **Cómo se utiliza (flujo general)**      | 1. Importar o recolectar datos <br>2. Definir nodos y aristas <br>3. Calcular métricas de red <br>4. Aplicar algoritmos de agrupamiento <br>5. Visualizar y ajustar el grafo <br>6. Interpretar resultados                                                                                    |
| **Rol dentro del curso**                 | NodeXL actúa como **puente conceptual** entre la teoría del Análisis de Redes Sociales y herramientas más avanzadas de Big Data, permitiendo comprender métricas, estructuras y visualizaciones antes de escalar a soluciones programáticas.                                                  |

Conceptos Fundamentales de Social Network Analysis (SNA)

| Concepto                                        | Descripción detallada                                                                          | Aplicación en NodeXL                                                 |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **Red (Network)**                               | Conjunto de entidades interconectadas mediante relaciones. Se modela como un grafo matemático. | Toda visualización y análisis parte de una red cargada en NodeXL.    |
| **Nodo (Vertex)**                               | Entidad individual dentro de la red (persona, cuenta, organización, hashtag).                  | Cada fila en la hoja *Vertices*.                                     |
| **Arista (Edge)**                               | Relación entre dos nodos; puede representar interacción, comunicación o vínculo.               | Definida en la hoja *Edges*.                                         |
| **Red dirigida**                                | Red donde las relaciones tienen dirección (A → B).                                             | Ej. menciones o retuits en Twitter.                                  |
| **Red no dirigida**                             | Red donde la relación es bidireccional (A — B).                                                | Ej. amistad o coautoría.                                             |
| **Grado (Degree)**                              | Número de conexiones de un nodo. Refleja actividad o popularidad.                              | Métrica básica calculada automáticamente.                            |
| **Grado de entrada (In-Degree)**                | Número de aristas que llegan a un nodo.                                                        | Indica visibilidad o influencia recibida.                            |
| **Grado de salida (Out-Degree)**                | Número de aristas que salen de un nodo.                                                        | Mide nivel de actividad o emisión.                                   |
| **Centralidad de intermediación (Betweenness)** | Mide cuánto un nodo actúa como puente entre otros nodos.                                       | Identifica brokers, líderes o mediadores.                            |
| **Centralidad de cercanía (Closeness)**         | Indica qué tan cerca está un nodo de todos los demás.                                          | Mide rapidez potencial de difusión.                                  |
| **Centralidad de eigenvector**                  | Considera tanto la cantidad como la importancia de las conexiones.                             | Identifica actores influyentes estructuralmente.                     |
| **Densidad**                                    | Proporción de conexiones existentes respecto al total posible.                                 | Evalúa cohesión general de la red.                                   |
| **Componentes**                                 | Subredes desconectadas entre sí dentro de la red global.                                       | NodeXL identifica componentes automáticamente.                       |
| **Comunidad (Cluster)**                         | Grupo de nodos con mayor interacción interna que externa.                                      | Detectada con algoritmos como Clauset-Newman-Moore.                  |
| **Modularidad**                                 | Métrica que cuantifica la calidad de la partición en comunidades.                              | Útil para validar segmentación de la red.                            |
| **Hubs**                                        | Nodos con alto grado que concentran conexiones.                                                | Identificados por métricas de centralidad.                           |
| **Autoridades (Authorities)**                   | Nodos que reciben enlaces de hubs importantes.                                                 | Aplica principalmente en redes dirigidas.                            |
| **Camino (Path)**                               | Secuencia de nodos conectados entre dos nodos.                                                 | Base para métricas de distancia.                                     |
| **Longitud promedio del camino**                | Distancia media entre pares de nodos.                                                          | Analiza eficiencia de la red.                                        |
| **Visualización de red**                        | Representación gráfica de nodos y aristas.                                                     | NodeXL ofrece múltiples layouts (Fruchterman-Reingold, Harel-Koren). |
| **Atributos de nodos/aristas**                  | Variables adicionales que describen características.                                           | Se usan para color, tamaño, filtros y análisis.                      |
